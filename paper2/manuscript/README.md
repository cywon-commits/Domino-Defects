# Paper II manuscript draft

- `main.tex` — REVTeX 4.2 source (same class and options as Paper I). Compile with `pdflatex main.tex` (twice).
- `figs/` — all 15 figure PDFs, generated by `paper2/mkfigs_ms1.py`, `fig_mono_ms.py`, `mkfigs_ms2.py` from `data/paper2_*.json`.

  (REVTeX was not installed where the draft was written). Line breaks and float placement will differ
  from the real REVTeX output. Do not use the stub for submission.
